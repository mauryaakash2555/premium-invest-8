# Intelligence Engine (Day 1)

Logic-only, modular financial simulation engine (India-first) intended to power 200+ tools.

## Core capabilities (implemented scaffolding)
- Time travel across years (monthly stepping + yearly snapshots)
- Market cycles: bull / bear / sideways (schedule-driven)
- Behaviour toggles: panic / discipline / delay
- Asset buckets: Stocks (equity-like), FD (debt-like), plus stubs for MF/SIP/Insurance
- Tax, inflation, opportunity cost hooks
- Parallel timelines (run multiple scenarios)
