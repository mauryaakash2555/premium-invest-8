NOT a calculator. NOT a broker. NOT a comparison site.

- Teaches through consequence, not advice
- Simulates market reality, not theory

## 🇮🇳 INDIA-FIRST RULES

- Currency: Always ₹ (INR)
- Tax: LTCG/STCG per current SEBI rules
- Inflation: 5-7% baseline
- Market hours: NSE/BSE timing
- Regulation: Exit loads, lock-ins, TDS

---

## 🎓 DESIGN PRINCIPLES

1. **One Engine, Many Modes**
   - Core simulator powers everything
   - UI consumes engine outputs only

2. **No Advice, Only Consequences**
   - "If you do X, then Y happens"
   - User decides, system educates

3. **Progressive Disclosure**
   - Simple for beginners
   - Deep for professionals
   - Complexity on demand

4. **Behavior First**
   - Returns matter less than discipline
   - Emotional cost > expense ratio
   - Real > theoretical
