# BM Wealth - Mutual Fund, LIC, PMS, Insurance, Trading, Wealth Management, FD Tool in Mumbai

## Overview
BM Wealth is a comprehensive open-source financial advisory tool for Mumbai investors, offering expert guidance on mutual funds, LIC, PMS, insurance, trading, wealth management, and FD. Built with secure, compliant features for personalized investment strategies. Led by Brahmdeo Maurya, dedicated to empowering Mumbai investors with tailored financial solutions.

- **Key Features**:
  - Mutual Fund calculator and recommendations for Mumbai.
  - LIC plans analysis.
  - PMS portfolio management tools.
  - Insurance quotes and comparisons.
  - Trading insights with real-time data.
  - Wealth management strategies.
  - FD rates and SIP guides.
