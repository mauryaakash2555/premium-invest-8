# Tech Terms Explained Simply 📖

**API**: A “door” your website uses to ask the server for help.

**Component**: A reusable UI LEGO block (like a button).

**Console**: A place to see errors (press F12).

**Database**: A place where data lives (Supabase).

**Deploy**: Publish the website so others can use it.

**Environment variables**: Secret settings in `.env.local`.

**Feature flag**: A switch to turn a feature ON/OFF.

**Frontend**: What users see and click.

**Backend**: Behind-the-scenes code (usually `app/api/*`).

**Lead**: A potential customer (email/phone/name).

**Localhost**: Your local testing website: `http://localhost:3000`.

**Provider**: An AI service (Gemini/Groq/Claude).
