# Video Tutorial Scripts 🎥

## Video 1: Changing Colors (2 minutes)

**Script:**
“Hi! Today we will change the site’s gold color.

1) Open `config/constants.js`
2) Ctrl+F → search `COLORS`
3) Change `PRIMARY_GOLD`
4) Save (Ctrl+S)
5) Refresh browser

Done!”

---

## Video 2: Changing Welcome Message (1 minute)

**Script:**
“Open `components/user/AIChatFloat.jsx`.

Ctrl+F → search for the welcome message.
Change the text, save, and refresh.

Done!”

---

## Video 3: Turning Features On/Off (2 minutes)

**Script:**
“Open `.env.local`.

Add `FEATURE_ANALYTICS=false`.

Restart server: `npm run dev`.

Done!”

---

## Video 4: Troubleshooting (4 minutes)

**Script:**
“When something breaks:
1) Press F12 → Console → find red error lines
2) Open `/api/health`
3) Hard refresh (Ctrl+Shift+R)
4) If still broken: delete `.next` and restart dev server
”
