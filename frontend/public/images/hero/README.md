# Hero Images

This directory contains hero images for the following pages:

- about-hero.webp - Hero image for About page
- services-hero.webp - Hero image for Services page
- blog-hero.webp - Hero image for Blog page
- contact-hero.webp - Hero image for Contact page
- compliance-hero.webp - Hero image for Compliance page

Note: Images should be in WebP format for optimal performance.
Recommended dimensions: 2000x1200px or similar landscape format.
